# 출애굽기 열 재앙 어드벤처 MVP 설계

## 목표

기존 점프맵을 출애굽기의 첫 세 재앙을 차례대로 경험하는 5~10분 분량의 스토리형 생존 어드벤처로 교체한다.

## 진행

1. 모세 NPC와 대화해 이야기를 시작한다.
2. 피로 변한 강 주변에서 깨끗한 물 항아리 3개를 수집한다.
3. 개구리 떼를 피해 제한 시간 동안 안전지대에서 생존한다.
4. 이·각다귀 재앙 중 천막 주변의 약초와 천 등 구호 물자 3개를 모은다.
5. 완료 후 다음 재앙이 추후 추가된다는 안내를 표시한다.

## 구조

- 서버가 사막 마을, 나일강, 궁전 입구, NPC, 수집물과 개구리 위험 요소를 생성한다.
- 플레이어별 Chapter, Objective, Remaining 상태를 관리한다.
- RemoteEvent가 장면 제목, 목표, 타이머, 대사를 클라이언트 UI에 전달한다.
- 기본 PlayerModule이 없는 현재 Studio 환경에서는 기존 대체 WASD·3인칭 카메라를 유지한다.

## 실패와 재시작

- 위험 요소에 닿아 사망하면 현재 장의 시작 지점에서 다시 시작한다.
- 생존 타이머는 해당 시도의 토큰으로 중복 실행을 막는다.
- 수집물은 플레이어별로 계산해 멀티플레이어 간 진행을 방해하지 않는다.

## 표현 원칙

성경 이야기의 흐름을 존중하는 모험·교육형 문구를 사용한다. 인물이나 재앙을 희화화하거나 과도하게 잔혹하게 묘사하지 않는다.
