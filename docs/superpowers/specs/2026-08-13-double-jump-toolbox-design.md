# 이중 점프와 도구 상자 설계

## 목표

점프맵에 공중 추가 점프와 상호작용형 도구 상자를 추가한다.

## 동작

- 플레이어는 지상 점프 후 공중에서 Space를 한 번 더 눌러 이중 점프한다.
- 시작 지점 옆 상자는 ProximityPrompt의 E 키로 연다.
- 상자는 플레이어별 한 번만 속도 코일을 지급한다.
- 속도 코일을 장착하면 WalkSpeed가 증가하고, 해제하면 기본값으로 복원된다.
- 사망하면 이미 획득한 플레이어에게 새 속도 코일을 다시 지급한다.

## 책임 분리

- 서버: 상자 생성, 소유권 기록, Tool 생성·재지급, 속도 검증.
- 클라이언트: Space 입력과 Humanoid 상태를 바탕으로 추가 점프 횟수 관리.
- 공용 설정: 점프 힘, 코일 속도, 상자 위치와 색상.

## 검증

정적 검사로 입력·상태 초기화·ProximityPrompt·중복 방지·장착/해제 효과를 확인하고, Studio에서 이중 점프, E 상호작용, 사망 후 재지급을 smoke test한다.
